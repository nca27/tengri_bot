# Tengri-бот: новости на казахском + словарик

Бот каждые 10 минут проверяет `t.me/s/tengri_kz`, берёт новые посты, просит Google Gemini
выбрать 5–10 слов и выражений среднего уровня и присылает вам в личку: текст новости,
под ним «слово — перевод» и ссылку на оригинал (с превью фото).

Всё бесплатно: бот работает на GitHub Actions (свой сервер не нужен), словарик делает
Gemini на бесплатном тарифе.

## Что понадобится (≈15 минут)

### 1. Создать бота
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя.
2. Скопируйте токен вида `123456:ABC...` — это `TELEGRAM_TOKEN`.
3. Откройте своего нового бота и нажмите **Start** (иначе он не сможет вам писать).

### 2. Узнать свой chat_id
Напишите боту **@userinfobot** — он ответит вашим `Id` (число). Это `CHAT_ID`.

### 3. Ключ Gemini API (бесплатно)
1. Зайдите на https://aistudio.google.com под своим Google-аккаунтом.
2. Слева **Get API key** → **Create API key**. Карту привязывать не нужно.
3. Скопируйте ключ (начинается на `AIza...`) — это `GEMINI_API_KEY`.

Если в вашем регионе AI Studio не открывается, напишите — подскажу обходной вариант.

### 4. Залить на GitHub
1. Зарегистрируйтесь на https://github.com, нажмите **New repository**.
   Сделайте его **Public** — для публичных репозиториев Actions бесплатны без лимита
   (ключи при этом никто не увидит, они хранятся в секретах).
2. Загрузите файлы из архива: **Add file → Upload files**. Папку `.github` тоже нужно загрузить —
   проще всего перетащить в окно сразу все файлы и папку целиком.
3. **Settings → Secrets and variables → Actions → New repository secret** — добавьте три секрета:
   `TELEGRAM_TOKEN`, `CHAT_ID`, `GEMINI_API_KEY`.
4. **Settings → Actions → General → Workflow permissions** → выберите **Read and write permissions** → Save.

### 5. Запустить
Вкладка **Actions** → `tengri-bot` → **Run workflow**. Через минуту придёт самая свежая
новость. Дальше бот работает сам каждые 10 минут.

## Полезно знать
- GitHub иногда запускает расписание с задержкой 5–15 минут — это нормально.
- Бот запоминает последний отправленный пост в файле `last_id.txt` (обновляется автоматически).
- Посты, где только фото или видео без текста, пропускаются.
- У бесплатного Gemini есть дневной лимит запросов. Бот сначала использует `gemini-3.8-flash`,
  а если её лимит кончился — `gemini-3.5-flash-lite`. Если недоступны обе, новость всё равно
  придёт, просто без словарика. Свои текущие лимиты видно в AI Studio.
- На бесплатном тарифе Google может использовать запросы для улучшения своих моделей.
  Здесь это тексты публичных новостей, так что ничего личного не уходит.

## Настройки
Можно задать через переменные окружения (в `bot.yml`, блок `env`):

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `GEMINI_MODELS` | `gemini-3.8-flash,gemini-3.5-flash-lite` | Модели по порядку: основная, затем запасные |
| `MAX_POSTS_PER_RUN` | `15` | Максимум постов за один запуск |
| `CHANNEL` | `tengri_kz` | Другой публичный канал |

Частоту проверки меняйте в `bot.yml`, строка `cron`.

Количество слов и уровень задаются текстом в `bot.py` (переменная `PROMPT`) — можно попросить,
например, «8–12 слов» или «уровень A2».

## Запуск на своём компьютере (вместо GitHub)
```bash
pip install -r requirements.txt
export TELEGRAM_TOKEN=... CHAT_ID=... GEMINI_API_KEY=...   # в Windows: set TELEGRAM_TOKEN=...
python bot.py --loop
```
Будет проверять канал каждые 10 минут, пока окно открыто.
